# 용어집 (glossary)

같은 개념은 아래 "정한 말" 하나로 씁니다. "쓰지 않는 말"이 보이면 정한 말로 바꿉니다. 단, **고유명사(회사·건물·상품·부서 이름), 앱 창 이름, 로직에서 비교에 쓰이는 문자열은 바꾸지 않습니다**(아래 맨 끝 "바꾸지 않는 것").

정할 때 기준: 코드에서 더 많이 쓰는 말, 실제 스타트업·서비스 운영에서 쓰는 말, 사용자가 준 예시(유입·이탈·순증감·개발 중·인력).

## 사람·조직

| 개념 | 정한 말 | 쓰지 않는 말 | 비고 |
|---|---|---|---|
| 플레이어 | 대표 | 사장, CEO(단독) | 화면 표기 "대표(나)" 유지. 앱 이름 "CEO 일정"은 앱 이름이라 유지 |
| 회사에 고용된 사람 | 직원 | 사원, 구성원 | 같은 부서 안 사람을 가리킬 때만 "팀원" |
| 일에 넣을 수 있는 사람 수 | 인력 | 사람 수, 일손 | "개발 인력", "배치 인력" |
| 조직 단위 | 부서 | 팀(단독 라벨) | A-237 부서=팀. 탭 이름이 "부서". "광고 운영팀"·"AI연구팀"처럼 부서 고유 이름과 "팀 채널"은 유지. "팀 탭" → "부서 탭" |
| 사람을 뽑음 | 채용 | 고용, 영입 | 스카우트 사건에서 "영입"은 대사 안에서만 허용 |
| 회사가 내보냄 / 직원이 나감 | 해고 / 퇴사 | 내보내기, 그만둠(라벨) | 뜻이 다르므로 섞지 않음 |
| 매달 주는 돈 | 월급 | 급여, 임금 | 인상 이야기는 "연봉 인상" 허용(실무 관용) |
| 직원 마음 상태 | 만족도 | 사기(라벨), 기분 | 서술은 "만족도가 떨어집니다". 다운라운드 문구의 "사기"는 만족도로 |

## 문장 꼴

## 바꾸지 않는 것

- 플레이스홀더 `{n}` `{name}` `${...}` `%s`, HTML 엔티티(`&quot;`), 태그, `\n`, 키 이름, `data-testid`.
- 로직에서 비교하는 문자열(`===`, `includes`, `startsWith`, `case`, 타입 유니언, id로 쓰는 값). 예: `pauseReason`의 "인수 제안이 들어왔습니다", 선택지 라벨 "정책자금…"·"은행…"·"월급…"·"직전 라운드…", 산업 단위 "고객사", 경로 "자력형"·"투자형", 광고 궁합 "보통", 메신저 묶음 "채널"·"외부 연락처"·"아는 사람", "[결과] " 접두. 바꾸기 전에 `grep -rn "원문" src scripts playtest`로 확인합니다.
- 고유명사: 회사·투자사·건물·상품·부서·사람 이름, 앱 창 이름(Desktop `APPS`).
