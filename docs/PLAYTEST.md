방법: `xvfb-run` 위에서 Playwright `_electron`으로 **실제 Electron 앱**을 띄우고(`playtest/driver.mjs`), `playtest/do.mjs`로 한 동작씩 클릭·입력했습니다. 동작마다 스크린샷을 남기고 그 파일을 직접 열어 보고 판단했습니다. 자동 판정(assert) 코드는 없습니다. 원본 스크린샷은 `playtest/shots/<회차>/`(용량 때문에 git 제외), 대표 장면은 `docs/shots/<회차>/`에 있습니다.

### 손으로 다시 계산한 숫자

- **지분 합 100%**: 수락 뒤 70.40 + 17.60 + 7.20 + 4.80 = 100.00% (800,000 + 200,000 + 81,818 + 54,546 = 1,136,364주). 셋업 80% + 20% = 100%.
- **투자금 = 포스트밸류 × 룸**: 엔젤 라운드 화면 862,400,000 ÷ (1 − 0.12) = 980,000,000, × 0.12 = 117,600,000 ✓. 미리보기(룸 10%) 855,000,000 ÷ 0.9 = 950,000,000, × 0.1 = 95,000,000 ✓. 신주 1,000,000 × 0.12 ÷ 0.88 = 136,363.6 → 136,364주, 리드 60% 81,818주. 투자사별 투자금 70,559,655 + 47,040,345 = 117,600,000 ✓.
- **기업가치(스코어카드)**: 팀 0.7 + 1,000×0.0004 + 0.15 + 0.1 = 1.35, 점수 = 1.35×0.3 + 0.5×0.25 + 0.5×0.25 + 0.5×0.1 + 1.0×0.1 = 0.805 → 8.05억 + 자금 0.5억 = 8.55억 ✓.
- **손익 = 총매출 − 부가세 − 영업비용 − 법인세**:
  - 1월: 월급 = 4,000,000 + 4,500,000 + (4,630,000 + 3,620,000) × 1/31 = 8,766,129 ✓, 4대보험 × 9.4% = 824,016 ✓, 퇴직연금 × 8.3% = 727,589 ✓, 접대비 52칸 × 2만 = 1,040,000 ✓, 홍보비 400만 → 영업비용 15,357,734 → 손익 = 0 − 0 − 15,357,734 − 0 = −15,357,734 ✓. 자금 50,000,000 + 117,600,000 − 15,357,734 = 152,242,266 = 화면 ✓.
  - 2월: 매출 4,607,143, 부가세 460,714(10%), 월급 16,750,000, 4대보험 1,574,500, 퇴직연금 1,390,250, 접대비 2,220,000 → 영업비용 21,934,750 → 손익 = 4,607,143 − 460,714 − 21,934,750 − 0 = −17,788,321 ✓. 3월 월초 자금 152,242,266 − 17,788,321 = 134,453,945 ✓.
- **결과 금액 = Exit 기업가치 × 창업자 지분율**: 1,522,180,078 × (800,000 ÷ 1,136,364 = 0.70399977) = 1,071,614,432 ✓. 다만 화면에 지분이 70.4000%로 반올림돼 0.704로 곱하면 1,071,614,775원(343원 차이) → **P1-17**.
- 지시 결과: 2(1인·1일) × 14일 × (1.2 + 1.2, A등급 2명) = 67.2 ✓. 성공 확률 0.75 + 0.04 + 0.08 = 0.87 ✓.
- 파산 판: 결과 0원 ✓(DEC-021).

### "다음에 뭘 해야 할지 알 수 있는가" (일반인·타이쿤 팬 눈으로)

- 셋업 4단계는 단계 표시와 설명이 있어 막힘 없음.
- 사무실 첫 화면의 "다음 할 일" 안내가 CEO 클릭을 알려줘서 좋음. 그러나 데스크탑을 열면 안내가 창 뒤에 가려짐(P1-03), 세일즈 직원이 쉬는데 "직원을 뽑으세요"라고 함(P1-11), 파산 직전에 아무 경고가 없음(P1-20).

### 손으로 다시 계산한 숫자

- 새 회사 예상 자금: (350만 + 380만) × 1.177 = 859.21만, 접대비 2칸 × 2만 × 31일 = 124만 → 5,000 − 859.21 − 124 = 4,016.79만 → "4,016만원" ✓

- 지분: 창업자 900,000주 ÷ 1,000,000주 = 90.000000% ✓(결과 화면)

### "다음에 뭘 해야 할지 알 수 있는가"

- 이어하기는 멈춘 상태로 열려 "▶ 계속"을 누르기 전에 화면을 볼 수 있어 좋음. 손상 복구 안내도 짧고 무엇이 일어났는지 알 수 있음.
- 탑뷰로 바꾼 뒤 처음 보는 사람도 사무실을 끌어 둘러볼 수 있고, 오른쪽 아래 둥근 버튼과 "끌어서 이동 · 휠로 확대" 안내로 조작을 알 수 있음. 대표 머리 위 "클릭!"과 안내 막대가 같은 말을 해 컴퓨터를 여는 법이 분명함.
