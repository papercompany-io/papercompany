# 화면 짜임·문구 가이드 (A-102 ~ A-111)

[DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)가 색·부품(토큰, 버튼, 탭)을 정한다면, 이 문서는 **앱 창 하나를 어떻게 짜고 무슨 말을 보여 주는지**를 정합니다.
기준 화면은 **채용 메뉴**(`src/ui/apps/HiringApp.tsx`)와 Startup Company의 예산 화면입니다. 새 화면·개편은 이 문서의 패턴을 먼저 조합하고, 없을 때만 새 클래스를 만듭니다.

## 1. 원칙

1. **채용 짜임을 먼저.** 왼쪽 회색 판(입력·지금 상태·요약) + 오른쪽 카드 목록(기록·대상). 한 화면에 결정은 한 군데에 모읍니다.
2. **한 번에 하나만 자세히.** 목록이 길면(투자사 12곳, 직원 N명) 왼쪽은 짧은 줄/카드, 누르면 오른쪽 판에 그 하나의 할 일만.
3. **숫자보다 뜻.** 영문 약어 대신 실무에서 쓰는 한국어 용어: "프리밸류" 대신 "투자 전 기업가치", "룸" 대신 "내줄 지분", 결과는 "받을 돈", "내 지분 100% → 90%". 공식은 `title` 툴팁이나 `?`(Help)로(A-245).
4. **게임 속 수치(효과량)는 숨김.** 플레이어가 수치를 보고 계산하게 하지 말고 느낌·결과로 배우게 합니다(아래 3절).
5. **AI 같은 카드 금지.** 색 윗줄 + 아이콘 동그라미 + 질문 제목 + 설명 한 줄을 모든 카드에 반복하는 템플릿은 쓰지 않습니다. 요약은 납작한 한 판(이름·숫자)으로.
6. **안내는 실제 동작과 맞게.** 단축키·메뉴 이름이 바뀌면 설정·힌트·미션 안내(`src/ui/hints.ts`, `src/data/missions.json`)도 함께 고칩니다.

## 3. 보여 주지 않는 것 (사용자 지시)

| 숨김 | 대신 |
|---|---|
| 복지 1인 비용·월 합계("1인 20만원"), 효과("만족 +6") | 이름·설명·켜짐 표시. 총 복지비는 직원 요약 한 칸 |
| 기능 효과 숫자("고객 유입 +3% · 입소문 +1.2") | 기능 설명 문장(`f.desc`) |
| 제품 화면의 국내 시장 크기·경쟁사 수·경쟁 평균·매력도 순위 | 우리 제품 상태만(사용자·매출·매력도·품질) |
| 레터 효과량 미리보기 | 보낸 **뒤**에만 "관심 +N", 이유는 다음 날 메신저 답장 |
| 광고 채널·캠페인 효과량(알리기/데려오기 배율, 궁합 숫자) | 궁합은 "우리와 잘 맞음/안 맞음" 말로, 효과는 지난 30일 성과·캠페인 결과로 |
| 아직 열리지 않은 부서 목록 문구 | 숨김 |
| 경기(호황/불황) 문구 | 뉴스 기사로만 |
| 고객사 미팅의 분위기·친밀도·카드 효과 숫자(A-186) | 참석자 몸짓("고개를 끄덕입니다"·"팔짱을 꼈습니다")과 표정, 친밀도는 "낯섦·아는 사이·친함·내 편", 카드는 하는 일과 쓰는 시간만 |

보이게 바꾼 것(A-196): 받쳐 주는 고객 수(SC의 잠재 사용자)는 숨기지 않습니다. 업무 창 상태·기능 탭에 "제품이 받쳐 주는 고객 약 N명 · N% 찼음" + 막대 + 할 일 한 줄, 시장·광고 창 시장별 줄. 사용자 "한계를 어디서 보는지, 있는지도 몰랐음".

## 4. 문구

- 한국어 존댓말 보고체("~합니다"), 짧게. 라벨은 명사형, 설명은 한 문장(A-245).
- 용어는 실제 스타트업·서비스 운영에서 쓰는 말로, [text-audit/glossary.md](../text-audit/glossary.md)를 따릅니다: 매출·비용·이익/손실·흑자/적자, 잔고, 런웨이, 기업가치(투자 전/후), 사용자 유입·이탈·순증감, 출시, 개발 중, 인력. 풀어 쓴 말(번 돈, 버틸 수 있는 기간, 회사 몸값, 들어옴/떠남)은 쓰지 않습니다.
- 영문 원어·전문 용어는 괄호로 한 번만: "투자 전 기업가치(프리밸류)", "다운라운드", "SAFE", "ESOP(직원 몫)".
- AI 문체 금지: 번역투("~을 통해", "~에 대한"), 억지 은유("들고 나는 길"), 질문형 라벨("누가 만드나"), 흐린 수식어("주로", "원래"), 과잉 안내("~해 보세요!"), 문장 중간 대시(뉴스 제목은 예외).
- 조사는 받침에 맞게(반응**이**, 품질**은**, 결제**를**). 이름 뒤 조사가 애매하면 `"구독 결제" 기능을`처럼 고정 명사를 붙입니다.
- 이모지 금지. 아이콘이 필요하면 `PxIcon`(coin·clock·check·warn·siren·trophy…) 또는 Codex 발주(전역 규칙).
- 대화(투자사·직원)는 화면 패널이 아니라 **메신저**로. 화면에는 "메신저에서 대화 보기" 버튼.

## 5. 지키는 것

- `data-testid`는 이름을 바꾸지 않습니다(플레이테스트·봇이 씀). 부품이 바뀌어도 같은 값을 같은 의미의 요소에.
- 공유 컴포넌트(`EmployeeDetail`은 사무실 직원 창에서도 씀)는 내보내기 모양을 유지.
- 좁은 창(900px 아래)에서도 깨지지 않게: 두 칸 짜임은 한 칸으로, 고정 폭 그림은 고정 크기로.
