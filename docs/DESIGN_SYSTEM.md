# 디자인 시스템 (A-86)

레퍼런스: Startup Company(위 막대·흰 창·밑줄 탭·회색 타일·조언자 말풍선·흰 동그라미 도구 버튼).
구현: `src/ui/theme.css` — 모든 CSS 뒤에 마지막으로 불러오는 층입니다.
화면 짜임(판·카드·요약 줄)과 문구·숨길 정보는 [SCREEN_GUIDE.md](SCREEN_GUIDE.md).

## 원칙

1. **면은 두 가지.** 어두운 *크롬*(위 막대·왼쪽 메뉴·책상 배치 도구·메신저 왼쪽) + 흰 *창*(앱 창·카드·목표·말풍선·모달).
2. **강조 색은 파랑 하나.** 초록 = 확정·돈 들어옴, 빨강 = 위험·삭제, 노랑 = 주의, 주황 = 크롬 안에서 "지금 켜짐"(배속·NEW).
3. **납작하게.** 그라데이션·입체 턱 없음. 1px 선 + 그림자 한 겹. 버튼은 각진 3px, 떠 있는 도구는 동그라미.
4. **색은 의미 토큰으로만.** 원색(`--c-*`)은 토큰 정의에서만 씁니다. 배경을 칠하는 규칙은 글자 색도 같이 정합니다.
5. **크롬은 스코프로.** `.chrome`(및 `.topbar`·`.sidebar`·`.desk-panel`·`.msg-side`)가 의미 토큰을 어두운 면 값으로 다시 정의합니다. 그 안에 넣은 버튼·칩·표는 손대지 않아도 어두운 면에 맞는 색을 받습니다.

## 부품

| 부품 | 클래스 | 규칙 |
|---|---|---|
| 버튼 | `.btn` (+`.green` `.red` `.ghost` `.gold` `.small` `.big`) | 납작한 면 + 같은 계열 진한 1px 테두리. 버튼 안 `.money`는 버튼 글자 색을 따름 |
| 탭 | `.tabs > .tab.on` | 글자 + 3px 파란 밑줄. 상자 없음 |
| 세그먼트 | `.seg button.on` | 회색 홈 안 흰 칸 |
| 타일 | `.cand` `.industry` `.spec-item` `.feat` … | 흰/회색 면, 올리면 연파랑 테두리, 고르면 `--surface-sel` |
| 칸 제목 | `.section-title` | 회색 띠 위 굵은 회색 글자 |
| 진행 막대 | `.bar` `.meter` `.ms-bar` | 흰 알약 홈 + 1px 테두리 + 색 채움 |
| 안내 | `.info` · `.warn` · `.ok` · `.err` | 하늘색 · 노랑 · 초록 · 빨강 면 |
| 창 | `.app-panel` | 흰 제목줄(색 아이콘 + 22px 제목 + 회색 ✕) / 흰 본문 |
| 말풍선 | `.hint` `.toast` | 흰 면 12px 모서리, 왼쪽 색 표식 |
| 도구 버튼 | `.round-btn` `.sb-icon` | 흰 동그라미 + 짙은 아이콘, 켜지면 파란 동그라미 + 흰 아이콘 |

## 새 화면을 만들 때

- 어두운 바탕에 부품을 놓을 땐 그 컨테이너에 `class="chrome"`을 붙입니다. 색을 따로 지정하지 않습니다.
- 데이터에서 오는 색(활동·카테고리 색)을 바탕으로 칠하고 흰 글자를 올릴 때는 흰 글자 대비 3:1 이상 되는 진한 색을 고릅니다.
- 대비 검사: 게임 화면에서 개발자 도구 콘솔로 모든 글자의 글자/바탕 대비를 계산해 3:1 미만을 찾습니다(A-86 작업 때 쓴 방법).
