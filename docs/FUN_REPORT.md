# 재미 측정 보고 (fun-loop)

`docs/prompts/fun-loop.md`의 바퀴마다 측정 → 진단 → 고침 → 재측정 결과를 남깁니다. 계측은 `scripts/sim/metrics.ts`(게임 규칙은 건드리지 않음), 숫자는 봇 측정값입니다.

## 측정 방법

- 커리어: `npm run sim -- 8 101`(전략 봇), `STRAT=novice npm run sim -- 8 101`(보통 봇) — 8커리어, 산업은 SaaS·소비자·커머스 순서.
- 첫 회사: `npm run sim -- 12 201 --one`, `STRAT=novice ... 12 201 --one` — 12개 회사, 초반 이탈을 봄.
- 의미 있는 결정 = 새로 생긴 고를 거리(사건 결정·외출 초대·외주 일감·인수 제안·라운드 변화) + 큰 행동(채용·기능 출시·단계 변화·이사·해외 진출). 위기 = 런웨이 3개월 미만 진입, S·A급 퇴사, 경쟁 사건.

## 0바퀴 — 기준선 (2026-10-22)

### 먼저 고친 것: 고객 인사이트가 쌓이지 않음

`src/core/product.ts`의 `insightGain`이 빈칸(항상 0)으로 커밋되어 있었습니다(A-115). 인사이트가 쌓이지 않아 핵심 기능 3개 뒤로 어떤 기능도 착수할 수 없었고, 결제 기능이 없으니 구독·거래 매출이 없어 거의 모든 회사가 파산했습니다(전략 봇 64개 중 60 파산, 보통 봇 64개 모두 파산, 모든 회사 "출시 3"). 커밋 `21cbc15`(광고 개편 묶음) 전후 비교로 찾았습니다(그 전 6개 중 상장 4 → 뒤 0). 데이터에 이미 있던 계수로 채웠습니다: 고객 인사이트 = userK × √사용자 + csK × 의견 수집 출력, 지불 의사 = payK × 돈 내는 고객^0.75.

봇 보정(규칙 아님): 결제 기능 전에는 영업해도 매출이 없으므로, 개발자가 없으면 대표가 결제까지 직접 개발(전략 봇만).

### 진단 — 가설 세 개

1. **초반 현금 위기에 쓸 수단이 없다(초반 이탈).** 보통 봇 첫 회사 10/12가 0.6~1.2년에 파산 → 원인: `finance.ts`에 빚(대출)이 없고, 위기 대응은 30일 걸리고 확률 10~20%인 투자 라운드(`funding.ts`)와 외주뿐. 런웨이 3개월 미만에서 고를 길이 사실상 하나 → 고칠 방향: 돈 시스템에 대가가 있는 단기 자금(정책자금 대출: 이자·상환·한도는 매출·신용에 따라) → 성공 기준: 보통 봇 첫 회사 1년 안팎 파산 10/12 → 6/12 이하, 전략 봇 상장 수는 줄지 않고, 대출을 늘 쓰는 지배 전략이 아님(봇 사용률 80% 미만, 이자 부담이 보임).
2. **잘되면 끝없이 커진다(결과 분산·후반 목표).** 전략 봇 8/8 같은 최고 엔딩, 회사 가치 수십조 → 원인: `market.ts` 수요·점유와 `valuation.ts` 배수가 큰 회사에서 꺾이지 않음, 경쟁사가 큰 우리에게 반응하지 않음(`competitors.ts`) → 방향: 시장 포화·경쟁 반격으로 성장에 천장과 대가 → 기준: 전략 봇 커리어 엔딩 3종 이상, 회사 최고 가치 중앙 1조 안팎.
3. **사건이 무작위 추첨이다(중반 정체·이야기).** 사건 카드는 하루 5~12% 확률 + 가중치 추첨(`events.ts` `eventsDay`/`trigger`), 회사 상황·직전 사건과 무관 → 방향: 긴장도 곡선을 따르는 스토리텔러(위기 뒤 쉼, 잘나갈 때 시련, 망해 갈 때 구원, 사슬) → 기준: 위기 간격이 고르게(몰림 줄고), 4년차 뒤 결정 밀도 하락 3할 → 1.5할 이하.
