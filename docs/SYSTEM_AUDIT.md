# 게임 시스템 감사 (fun-loop 브랜치, 2026-10-22)

`src/core/*.ts`와 짝이 되는 `src/data/*.json`, `docs/GAME_DESIGN.md`를 읽고 시스템마다 점수를 매겼습니다. 점수는 코드가 실제로 하는 일만 봤고, 설계서에 적혀 있어도 코드에 없으면 없는 것으로 쳤습니다.

점수 기준(1~5)
- 깊이: 1 = 숫자 하나 올리기, 5 = 여러 요인이 맞물리고 선택마다 대가가 있음
- 반응성: 플레이어 선택·회사 상태·다른 시스템에 따라 달라지는 정도
- 가독성: 효과 수치는 숨긴 채로, 메신저·뉴스·결정 이유로 "왜"를 알 수 있는 정도
- 다양성: 시드·산업·성격마다 다른 이야기가 나오는 정도
- 수명: 초반·중반·후반·다음 회사까지 역할이 이어지는 정도

### 가장 약한 시스템 5개
1. 경쟁사 AI(합 10) — 상대가 우리를 보지 않음
2. 사무실(합 10) — 효과가 쾌적도 합 하나
3. 외주·계약(합 11) — 단계 2에서 끝나고 아무것으로도 이어지지 않음
4. 대표(합 12) — 상태도 관계도 없는 점수 누적
5. 상장·매각(합 12)·메신저(합 14) — 끝판이 수동적이고, 이야기 통로가 출력 전용

| 사건 가격 전쟁 ↔ 경쟁사 월간 가격 인하 | 둘이 서로 모름 | `events.ts`(`applyFx`에 경쟁사 `boostUntil`), `competitors.ts` |
| 우리 가격·광고·출시 → 경쟁사 대응 | 경쟁사는 매력도만 봄 | `competitors.ts`, `ads.ts`(경쟁 광고 압력), `market.ts` |
| 투자자 → 이사회 요구·약속, 라운드 사이 기억 | `board` 숫자 하나, 투자사 채널은 라운드 뒤 조용함 | `funding.ts`, `exit.ts`(`checkBoard`), `messenger.ts`, `types.ts` |

| 크런치·과밀 → 노동 점검·노조 사건 | `ev_legal_labor_inspection`은 직원 수만 봄 | `events-a.json`(cond `crunch`, `satMax`), `events.ts` |
| 사무실 등급·쾌적도 → 채용·투자 인상 | 만족·건강에만 씀 | `hiring.ts`(`arrivalRate`), `funding.ts`, `office.ts` |
| 퇴사자 → 경쟁사 합류·다음 회사 재합류 | 퇴사하면 사라짐 | `staff.ts`(`removeEmployee`), `competitors.ts`, `state.ts`(`nextCompany`) |

## 3. 로드맵

원칙: 많은 시스템이 기대는 낮은 점수부터, 한 라운드에 시스템 하나 또는 연결 하나. 3~4라운드마다 통합 라운드. 수치·규칙 변경은 `balance-change` 스킬과 `npm run sim -- <판 수> <시드> --one` 전후 비교, 화면은 `screen-design` 스킬을 따릅니다. 성공 지표의 "재미 지표"는 `scripts/sim/metrics.ts`(30일당 결정, 빈 구간, 위기 간격)를 뜻합니다.

### 기반(시장·돈·제품)
- [ ] R1 제품: 기술 부채를 결과로 — `debt`가 장애 심각도·출시 실패 확률을 키우고 부채 사건 조건(`debtMin`)을 엽니다. 지표: 크런치 봇과 정상 봇의 회사당 장애 수 차이 2배 이상, 부채 사건이 플래그 없이 등장
- [ ] R2 시장: 고객 변화 이유 보고 — 월초 메신저 "고객 리포트"(가장 큰 이탈·획득 원인 말로, 수치 없음). 지표: 플레이테스트에서 "고객이 왜 줄었나" 질문에 화면만 보고 답한 비율 80% 이상
- [x] R3 돈 (1바퀴로 앞당김, A-137 — 기준선에서 초반 파산이 가장 큰 나쁜 신호였음. 대출만 구현, 감원·지급 유예는 남음): 버티는 수단 — 브릿지 대출(이자·약정), 지급 유예, 감원(위로금·남은 직원 만족 하락). 지표: 런웨이 3개월 미만 진입 회사 중 생존 30~70%(전부 살거나 전부 죽지 않음)
- [ ] R4 통합: 기술 부채 → 장애 → 이탈·언론 → 투자 관심 하락 연쇄. 지표: 같은 시드에서 부채를 방치한 봇의 다음 라운드 성공 확률이 눈에 띄게 낮음, 연쇄가 뉴스·메신저 두 곳에 보임

### 상대(경쟁사·투자자)
- [ ] R5 경쟁사: 성격 3종(가격형·기능형·광고형)과 우리 가격·출시·점유에 대한 대응, 투자금이 매력도·광고로 전환. 지표: 시드 10개에서 경쟁 서사(가격 전쟁·기능 경쟁·광고전) 분포가 한쪽 60% 이하
- [ ] R6 투자자: 관계 기억 — 라운드 뒤 기존 투자자의 근황 연락·후속 참여 의향, 이사회 약속(성장 목표)과 지키지 못했을 때 압박. 지표: 후속 라운드 기존 투자자 참여 사례가 회사당 1회 이상, 이사회 사건이 매출 하락과 상관
- [ ] R7 통합: 경쟁사 투자 유치 → 우리 핵심 인재 이직 제안(붙잡기 선택지) + 사건 가격 전쟁을 월간 경쟁사 상태와 한 몸으로. 지표: 이직 제안의 70% 이상이 직전 90일 안 경쟁사 투자 뒤에 발생

### 사람(채용·조직·대표)
- [ ] R8 사람: 퇴사 경로 — 이직 제안·카운터 오퍼·퇴사 면담 이유, DM "분발 부탁"에 짧은 출력 이득 대가 부여, 읽히지 않는 특성 효과(`polish`) 정리. 지표: 퇴사 알림의 90% 이상이 이유를 말함, 늘 손해인 행동 0개
- [ ] R9 조직: 죽은 지시 제거·의미 부여(`fl_compliance` → 법무 사건 확률·피해), 지시 변경을 `commandOrder` 한 길로. 지표: 효과 없는 지시 0개, 부서 지시 선택 분포가 봇 기본값 하나에 80% 넘게 몰리지 않음
- [ ] R10 대표: 체력·컨디션 상태(외출·크런치로 하락, 낮으면 판단 실수 사건), 네트워크를 "연락처"로 남김. 지표: 대표 휴식이 의미 있는 선택(휴식 0인 봇의 사건 실패율 상승), 연락처 수가 커리어 동안 증가
- [ ] R11 통합: 경기 하강 → 투자 냉각 → 브릿지·감원 → 사기 하락·퇴사 연쇄 + 연락처에서 오는 채용 추천·투자사 소개·대기업 소개. 지표: 불황 진입 뒤 12개월 안 감원 결정 사례, 연락처 기원 기회 연 2건 이상

### 이야기(사건·메신저)
- [ ] R12 사건: 스토리텔러 — 긴장도 값(런웨이·이탈·퇴사·경쟁)으로 사건 확률·종류 가중, 큰 위기 뒤 회복 구간, 실제 상대 경쟁사 지정. 지표: 재미 지표 60일 넘는 빈 구간 0, 위기 간격 중앙값 60~120일
- [ ] R13 메신저: 고객·언론·경쟁사 목소리 채널, 뉴스가 인지도·명성·주가에 작은 기간 효과. 지표: 비시스템 발신 메시지 비율 증가, 뉴스 1건당 이어진 효과 확인
- [ ] R14 사건: 후반 카드 보강(`stageMin ≥ 4` 0개 → 20개 이상, 상장 전후 거버넌스·M&A·규제). 지표: 5년차 이후 30일당 사건 수가 초반의 70% 이상
- [ ] R15 통합: 크런치·과밀 → 노동 점검·노조, 외주 고객사 → 첫 고객·대기업 후보. 지표: 노동 사건의 다수가 크런치·만족 저하 상태에서 발생, 외주 고객 출신 계약 사례

### 장기(상장·커리어·레거시)
- [ ] R16 상장·매각: 상장사 이사회·주주 압박(가이던스 연속 미달 → 해임 위험), 인수자 성격(전략적·재무적·경쟁사). 지표: 상장 뒤 사임까지 의미 있는 결정 30일당 수가 상장 전의 70% 이상
- [ ] R17 사무실: 공간 효과(회의실·라운지·집중석 배치가 협업·건강에), 사무실 등급이 지원자·투자자 인상에. 지표: 이사 결정 이유가 책상 수 말고도 생김(봇·플레이테스트 기록)
- [ ] R18 커리어: 연쇄 창업 이어짐 — 전 직원 재합류 제안, 투자사 기억, 엔젤 투자(설계서 3.9) 구현. 지표: 두 번째 회사 첫 해 결정 중 이전 회사 인연 기원 비율 20% 이상
- [ ] R19 통합: 퇴사자 → 경쟁사 합류·재회 사건, 상장 이후 결과 → 레거시·엔딩 문구 반영. 지표: 커리어 엔딩 요약에 개별 사람·회사 이름이 3개 이상 등장
