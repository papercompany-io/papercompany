# 페이퍼컴퍼니 게임 설계서 v2 (완성형)

기준: 기획 SSOT(https://claude.ai/artifact/PyN3znzaqJWiNcGBtEkMjn, 읽기 전용)의 결정(DEC)과 기능 명세(F01~F14)를 따른다. v1(MVP)에서 범위 밖으로 둔 기능(PD·RV·DC·EM-03/04·OP·WF·AT·OF-03/05/07·DT-03/04/08·FR-12·EQ-04·CA-03·EX-05·RK-01·ED)을 이번 판에서 구현한다. SSOT가 정하지 않은 규칙은 [Claude 제안]으로 `ASSUMPTIONS.md`에 남긴다. 수치는 모두 `src/data/*.json`의 [예시값]이며 밸런싱 시뮬레이터(`scripts/sim`)로 조정한다.

## 1. 한 줄 요약과 판의 구조

창업자 한 사람의 **커리어**(30세, 2027년 → 은퇴 65세)를 플레이한다. 커리어 동안 회사를 여러 번 세우고(연쇄 창업), 각 회사는 창업 → MVP → 성장 → 확장 → 상장·매각(또는 파산)으로 끝난다. 회사가 끝날 때 창업자 개인 자산과 명성이 쌓이고, 은퇴하면 **최종 자산 + 레거시**로 엔딩과 명예의 전당이 정해진다. (SSOT SC-01의 "결과 금액 = Exit 기업가치 × 지분율"은 회사 한 판의 결과로 그대로 쓰고, 커리어는 그 결과를 이어 붙이는 상위 구조다 — ED·RK 확장, OQ-020 은퇴 엔딩을 채택.)

| 층위 | 기간(게임) | 핵심 질문 |
| --- | --- | --- |
| 커리어 | 최대 35년 | 어떤 산업에서 몇 번 창업하고 언제 은퇴할까 |
| 회사 한 판 | 보통 4~12년 | 투자로 빠르게 vs 매출로 단단하게, 언제 Exit할까 |
| 분기·월 | 1~3개월 | 어떤 기능을 만들고 어느 시장을 노리고 누구를 뽑을까 |
| 하루 | 1일(1배속 6초) | 대표 칸 배분, 이벤트 결정, 지시 |

## 3. 경제 시뮬레이션(시스템 간 연결)

```
대표 칸 ─┐                        ┌─ 마케팅(인지도) ─┐
부서 지시 ┼─→ 작업량 → 기능 개발 → 제품 매력도 ─┼→ 시장 점유 → 신규 고객 ─→ 매출 → 손익 → 자금
직원(등급·사기·건강·AI) ┘          └─ 품질(버그) ─→ 이탈 ←─ CS·가격 ┘              ↑        │
경쟁사(매력도·가격·자금) ──→ 점유율 다툼                       인프라 비용·월세·복지·인건비 ┘
매출·성장·이익 → 기업가치 → 투자·Exit·주가 → 창업자 지분 가치 → 커리어 자산
```

### 3.1 제품(PD)
- 산업마다 기능 트리 30~45개(선행 조건, 등장 연도). 기능 = 개발 작업량 + 디자인 작업량, 효과(매력도·전환·유지·객단가·바이럴·인프라 비용·기업 고객 대응·시장 진출 조건).
- 기능은 개발팀 지시 "기능 개발: ○○"로 만든다. 진행률은 부서원 출력의 합(등급·숙련·사기·건강·AI 배율·팀장).
- 품질: 개발할 때마다 버그(기술 부채)가 쌓이고, "안정화" 지시·QA·인프라 팀이 줄인다. 버그가 많으면 이탈↑, 장애 이벤트↑.
- 제품 매력도 = 기능 가치 × 디자인 완성도 × 품질 계수. 시장마다 경쟁사 매력도와 비교한다.

### 3.2 시장·고객·매출(RV)
- 시장: 국내 → 일본·동남아·미국·유럽(해외 진출은 현지화 기능 + 해당 시장 영업 투입). 시장마다 잠재 고객(TAM)이 해마다 자라고 경기 순환을 탄다.
- 하루 신규 고객 = 남은 잠재 고객 × 인지도 × 점유 매력(로짓) × 전환율 + 영업 직접 계약 + 바이럴.
- 이탈 = 기본 이탈 × 버그 계수 × 가격 계수 × 경쟁 열세 계수 − CS 효과.
- 가격 정책(저가·표준·프리미엄)은 전환·이탈·객단가를 바꾼다. 산업별 매출 방식: 구독(B2B SaaS), 광고+프리미엄(소비자 앱), 거래 수수료(커머스), 수수료+이자(핀테크).
- 고객 비용: 고객 수에 비례하는 인프라 비용(DEC-002: 서버를 직접 관리하지 않음, 인프라 부서·기능이 단가를 낮춤).

### 3.3 경쟁사
- 산업마다 가상 경쟁사 4~6곳(이름은 패러디 가상명, RSK-11). 각자 매력도·고객·자금·공격성을 갖고 매달 성장·투자 유치·가격 인하·기능 출시·폐업.
- 4단계부터 인수 제안 가능(EX-05의 반대 방향): 경쟁사 기업가치를 치르고 고객·매력도 일부를 흡수.

### 3.4 인력(HR·EM·OP·WF)
- 직원: 등급 S~C, 숙련(근속에 따라 상승), 특성 2개(EM-03, 16종), 만족도·건강(DEC-022).
- 만족도 요인: 시장 대비 월급, 복지, 사무실 등급, 회사 성장세, 야근(크런치 지시), 조직 문화, 팀장 유무, 스톡옵션. 낮으면 출력↓, 매달 퇴사 확률↑(EM-04), 연봉 협상·이직 제안 이벤트.
- 건강: 크런치·과밀로 하락, 낮으면 병가. 헬스비·병원비 복지가 막고 회복시킨다.
- 팀장: 부서 7명 이상이면 팀장이 없을 때 효율 감소(관리 범위). 승진시키면 월급↑·부서 효율↑.
- 부서: 개발·디자인·세일즈·마케팅·인사(기존) + CS(이탈↓)·인프라(인프라비↓, 장애↓)·재무법무(세금·규제 위험↓, IPO 준비)·AI연구(AI 기능·도구 효율). 부서는 단계·사무실로 열린다.
- 복지(WF): 식대, 장비, 헬스비, 병원비, 유연근무, 교육비 — 직원 수만큼 월 비용, 공고에 표시되어 지원자 수·질↑.
- 사무실(OF-07): 공유오피스 → 작은 사무실 → 중형 → 대형 한 층 → 사옥. 보증금 + 월세, 좌석·부서 구역·쾌적도(만족도)↑. 이사하면 박스 연출(OF-03).

### 3.5 AI 도입(AT)
- 연도에 따라 가상 AI 공급사 3곳의 도구가 나온다. 부서별 적용률(0~100%) × 공급사 성능 = 출력 배율, 좌석당 구독료. 공급사 성능이 업데이트로 오르내리고, "AI 슬롭"(품질 저하·버그) 위험, 공급사 교체(전환 비용).

### 3.6 이벤트와 결정(DC)
- 조건(단계·산업·지표·연도·경기)에 맞는 이벤트 카드가 확률로 뜬다. 메신저 메시지 + 결정 창(선택지 2~4개, 비용·확률 결과). 긴급 이벤트는 시간을 멈춘다(DT-04).
- 120종 이상: 인재 이직 제안, 장애, 해킹, 언론 인터뷰, 대기업 제휴, 소송, 규제, 직원 갈등, 투자자 압박, 경쟁사 가격 전쟁, 붐·불황, 정부 지원 사업, 인수 제안, 바이럴 대박, 공동창업자 갈등 등.
- 경기 순환(호황·보통·불황, 1~3년 주기)이 투자 확률·기업가치 배수·고객 획득에 영향. 회사 소식 피드(UX-13 "페이퍼뉴스").

### 3.7 투자·지분(FR·EQ)
- 기존 엔젤~시리즈 G + SAFE(FR-12, 시드까지, 다음 라운드에 밸류캡·할인으로 전환) + ESOP 풀(EQ-04, 베스팅) + 다운라운드. 투자자 지분이 과반이면 이사회 압박 이벤트.

### 3.8 Exit·상장사
- 매각·IPO(기존) + 먼저 들어오는 인수 제안(EX-05). IPO 성공 뒤에도 회사는 계속: 주가(공정가치 × 심리, 매일 변동), 분기 실적 발표(가이던스 대비), 락업 180일 뒤 창업자 지분 매각으로 개인 자산 실현, 행동주의·적대적 인수 이벤트.
- 회사 한 판이 끝나는 경우: 매각 성공, 상장 후 지분 대부분 매각하고 사임, 파산(FL-01), 이사회 해임.

### 3.9 커리어·메타
- 회사 종료 → 커리어 화면: 개인 자산, 명성, 레거시 점수. 다음 창업(산업 선택, 개인 돈 투입 가능), 엔젤 투자(다른 스타트업에 투자, 결과는 몇 년 뒤), 은퇴.
- 명성은 다음 창업의 스펙 예산과 초기 투자 확률을 올리고, 첫 Exit 뒤에는 "엑싯 경험"을 자동으로 갖는다(DEC-024와 연결).
- 레거시 강화: 산업 해금(핀테크·AI 플랫폼), 시작 크레딧, 네트워크, 채용 질 등.
- 엔딩(ED): 은퇴 시 자산·업적으로 여러 엔딩. 명예의 전당(RK-01, 로컬). 업적 60개 이상. 도전 모드(불황 시작, 1인 창업, 무투자 상장 등).

## 4. UX·피드백
- 튜토리얼 미션(챕터별 목표 체인)과 "다음 할 일", 처음 열리는 앱마다 짧은 안내.
- 알림 토스트·앱 배지(DT-04), 효과음(칩튠, 음량 설정), 사무실 연출(입사 박스·이사·말풍선 아이콘·떠오르는 +고객/+매출), 마일스톤 축하 연출, 숫자 변화 강조.
- 설정 앱(DT-08): 음량, 자동 일시정지, 기본 배속. 단축키(스페이스 일시정지, 1~4 배속).

## 5. 플레이타임 목표와 검증 방법
- 1배속 하루 6초, 1년 36.5분. 측정은 두 가지로 한다: (1) 전략 봇 시뮬레이션으로 단계 도달 게임일수와 결정 횟수, (2) 실제 앱 직접 조작 플레이테스트. 보고에는 측정한 값만 쓴다.
- 목표(측정으로 확인할 것): 첫 회사 MVP 2~4개월, 시리즈 A 1~2년, 상장 가능 6~10년. 커리어 35년 동안 회사 3~5개. 각 단계에서 새 시스템·선택지가 열리는 간격이 게임 시간 2~4개월 이하.
- 실패 경로가 있어야 한다: 무리한 채용·과속 개발·가격 전쟁·불황에서 파산 가능, 같은 전략이 매번 통하지 않도록 산업·경기·경쟁사가 다르다.

### 5.1 측정 결과(5회차, 2026-10-21)
측정한 값:
- 실제 앱: 1배속 6초/일, 4배속 약 1.4~1.5초/일(직원 9명·146명 모두). 손으로 운영한 회사 두 개의 게임 길이 486일(매각)·915일(파산). 첫 회사 MVP 49일, 두 번째 회사(창업 경험 있음) 48일.
- 전략 봇 4커리어: 커리어 33.1~35.0년, 회사 5~6개, 결정 1,324~1,429번, 1배속 게임 시간 20.1~21.3시간. 회사 22개 중 상장 19·파산 3. 봇 첫 회사 마일스톤(산업 3종 표본): MVP 73~77일, 시드 0.8~1.5년, 시리즈 A 1.2~1.9년, 상장 5.8~6.0년(상장한 2개), 상장 뒤 사임까지 포함한 회사 길이 8.0~10.3년.
- 손 플레이(나): 첫 커리어의 두 회사가 자금난 매각(6.8억)·파산. 봇은 커리어마다 최고 엔딩 — 숙련도에 따라 결과가 크게 갈린다.

추정(측정이 아님): 한 커리어를 1배속 위주로 하면 게임 시간 약 21시간 + 결정 약 1,300번(한 번 10~20초로 잡으면 3.6~7시간) + 채용·로드맵·라운드 관리. 2·4배속을 섞으면 게임 시간 부분이 절반 이하로 줄어 한 커리어 약 12~18시간. 30시간 이상은 커리어 두 번(레거시 강화·핀테크/AI 해금·도전 모드로 조건이 바뀜) 또는 1배속 위주 한 커리어 + 다음 커리어 일부로 보는 것이 맞다. 사람이 한 커리어를 끝까지 손으로 해 본 측정은 아직 없다(5회차는 한 커리어 안의 회사 두 개 + 봇이 상장시킨 저장으로 후반).

### 시작 상태(A-78)
창업자는 빈 원룸 작업실에서 책상 하나로 혼자 시작한다(자본금 5,000만원). 제품(MVP)을 만들고, 사람을 뽑을 때마다 책상·PC가 늘고, 가구를 사서 들이고, 더 큰 사무실로 옮기며 화면 속 회사가 실제로 커진다. 첫 사무실(창업 사무실) 이전은 미션 "첫 사무실"로 안내한다.
